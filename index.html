¿Cómo instalar en Android?

  1. Toca en Descargar APK.
  2. Si el navegador muestra una advertencia de archivo no reconocido, selecciona "Descargar de todos modos".
  3. Abre el archivo descargado y concede el permiso para "Instalar aplicaciones desconocidas" si el sistema lo solicita.
  4. ¡Abre Locky y accede a tu bóveda!
